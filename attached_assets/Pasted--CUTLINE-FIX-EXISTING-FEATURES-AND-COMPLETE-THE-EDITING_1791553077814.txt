# CUTLINE — FIX EXISTING FEATURES AND COMPLETE THE EDITING WORKFLOW

Continue working on the existing Cutline Video Editor project. The application already has a Media panel, video preview, timeline, Audio 1, Text 1, title templates, a Clip Inspector, playback controls, and basic project controls.

Do not rebuild the project or redesign everything from scratch. Inspect the current source code, identify which features are implemented, and fix the existing implementation. Preserve working features and user projects.

The current problem is that many controls appear in the UI but do not work reliably. Focus on real functionality, not just appearance.

## 1. MAKE THE VIDEO PREVIEW LARGER

The video preview currently appears too small inside the available central workspace.

* Increase the preview's usable width and height.
* Use the available central workspace efficiently without unnecessarily shrinking the Media panel or Clip Inspector.
* Keep the video centered and scale it proportionally.
* Preserve the entire source frame by default.
* Never stretch or accidentally crop the video.
* Support 16:9, 9:16, 1:1, and other aspect ratios.
* Allow the preview workspace to resize with the browser window.
* Add useful Fit, 100%, and Fit to Canvas preview controls where appropriate.
* Separate preview zoom from the actual clip scale.
* Keep playback controls accessible below the preview.

The preview should be as large as practical within the current layout, especially on a 1920×1080 desktop display. It must remain usable at 1366×768.

## 2. AUDIO MUST PLAY CORRECTLY

When I press Play, the video's audio must play whenever the source contains audio.

Inspect the actual playback implementation:

* Check whether the browser video element is muted accidentally.
* Ensure playback controls update the correct video/audio sources.
* Respect master volume and clip gain.
* Make sure the volume slider changes actual playback volume.
* Make sure the mute button really mutes and unmutes the audio.
* Check that the browser is not playing duplicate audio sources.
* Synchronize audio and video when clips are moved or trimmed.
* Support audio clips on Audio 1 and additional audio tracks.
* Make sure playback follows the timeline arrangement.
* Preserve audio in the final export.

Browser autoplay restrictions must be handled correctly. Start audio after the user's Play interaction when necessary.

If a source contains no audio, display that clearly rather than silently pretending an audio track exists.
