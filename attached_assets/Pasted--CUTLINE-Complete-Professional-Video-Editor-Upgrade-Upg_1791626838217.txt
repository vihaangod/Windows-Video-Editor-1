# CUTLINE — Complete Professional Video Editor Upgrade

Upgrade the existing Cutline video editor into a reliable, professional, timeline-based video editing application. First inspect the entire existing codebase, architecture, UI, project storage, timeline engine, preview renderer, media handling, and export pipeline.

Implement the requirements below in the existing application. Preserve the current dark-and-gold theme, existing projects, and all working features.

**Critical rules:**
- Build real, functional features, not UI-only placeholders.
- Do not replace the existing project with a new application.
- Do not unnecessarily rewrite working code.
- Reuse and improve existing components wherever possible.
- Fix existing bugs related to these features before adding duplicate functionality.
- Ensure the timeline preview and exported video use the same editing logic.
- Keep performance suitable for a laptop with an Intel Core i3, integrated graphics, and 8 GB RAM.
- Test the actual workflows and report only verified results.

# 4. Dedicated Filter / Effects Timeline Track

Implement a proper timeline-based filter/effect system similar to professional video editors.

## Dynamic Effects Track

- Add a dedicated Filter / Effects track below the video tracks when it is needed.
- Do not show an empty Effects/Filters track in a new project.
- When the first filter or effect is applied, create the track automatically.
- Keep the track visible while it contains effect clips.
- Hide it when its last effect clip is removed.
- Restore it correctly when reopening the project.

## Creating Filter Clips

When the user selects and applies a filter:
- Create an individual filter clip on the Effects/Filters track.
- Set its default duration to 5 seconds.
- Start it at the current playhead position.
- If no video clip is selected, apply it to the appropriate video clip under the playhead.
- If no valid target video exists, show a helpful message.
- Do not automatically apply a selected filter to the entire video.
- Display the filter name, duration, and a distinct visual style inside the timeline clip.

Support multiple filter clips at different times.

## Filter Clip Editing

Allow users to:
- Move the entire filter clip.
- Drag its left edge to change the start time.
- Drag its right edge to increase or decrease duration.
- Set an exact duration through a numeric field or equivalent control.
- Select, duplicate, and delete individual filter clips.
- Adjust the intensity of each filter clip independently.
- See clear visual feedback when selecting or resizing a clip.
- Use timeline zoom and scrolling normally.

Filter clips should not extend beyond their intended target video clip unless the existing architecture explicitly supports such behaviour.

## Filter Timing

Example:
- Video duration: 30 seconds.
- Cinematic filter: 0–5 seconds.
- Vintage filter: 10–15 seconds.
- The remaining sections retain their original appearance unless another effect is active.

Apply a filter only while the playhead is within that filter clip's active time range.

When the playhead exits the range, restore the original appearance unless another active effect applies.

Support multiple non-overlapping filters. Define predictable behaviour for overlapping filters, allowing compatible effects to combine or providing a clear conflict rule.

Never permanently modify the original source video when applying a filter.

## Interaction with Other Editing Operations

Handle filter clips correctly when the associated video is:
- Split
- Trimmed
- Moved
- Duplicated
- Deleted
- Repositioned through timeline operations

Keep filter timing and target associations valid after these changes.

## Exact Preview and Export Timing

- Activate and deactivate effects at the correct frame.
- Use the same filter settings and timing in preview and export.
- Do not apply timeline filters globally during export.
- Preserve original audio, FPS, resolution, and aspect ratio unless the user changes export settings.

# 7. Correct Video and Audio Track Placement

Implement clear track placement rules.

## Main Video Track — V1

- Keep the main footage on V1.
- When the user adds a short video clip, insert it at the current playhead position on V1 by default.
- Never silently replace existing footage.
- If insertion affects existing clips, offer a clear insert/ripple option or ask the user whether to insert, use another track, or cancel.
- Preserve existing edits.

## Additional Video Tracks — V2, V3, etc.

Allow additional video tracks for:
- B-roll
- Overlays
- Picture-in-picture
- Secondary footage
- Layered video

Dragging a clip above V1 should place it on an appropriate additional track.

Create additional tracks only when needed.

## Audio Tracks — A1, A2, etc.

- Imported music, sound effects, and voiceovers should be placed on audio tracks.
- Use A1 by default when appropriate.
- If the track is occupied or overlapping audio is needed, create or use another audio track.
- Never overwrite existing audio automatically.
- Support audio trimming, splitting, moving, volume, mute, and fade-in/fade-out where supported.
- Synchronize audio playback and export with the timeline.

## Images and Overlays

- Place images, logos, and supported visual assets on an overlay-capable video track.
- Allow users to adjust duration, position, scale, and placement where supported.
- Preserve transparency when supported.
- Keep the main video visible beneath transparent overlays.

## Add to Timeline Behaviour

When a user selects a file in the Media Library and clicks Add to Timeline:
- Use the selected track and playhead when appropriate.
- Otherwise choose a sensible default based on media type.
- Ask for placement when the destination is ambiguous.
- Avoid accidental overwriting.
- If placement conflicts with existing content, use a suitable additional track or ask the user what to do.

# 9. Canvas Aspect Ratios and Correct Portrait Reframing

Fix and implement actual project canvas aspect ratio controls.

Provide these presets:

- Landscape 16:9 — 1920 × 1080
- YouTube Shorts / TikTok / Reels 9:16 — 1080 × 1920
- Instagram Portrait 4:5 — 1080 × 1350
- Square 1:1 — 1080 × 1080
- Custom dimensions if supported by the rendering engine

Landscape 16:9 should be the default.

## Aspect Ratio Is Not Preview Zoom

Keep Fit, Fit Canvas, and 100% as separate preview zoom controls.

Changing preview zoom must not change the project's actual aspect ratio or export dimensions.

## Fit, Fill, and Crop

Implement three distinct modes:

**Fit**
- Show the entire source video inside the canvas.
- Preserve the original proportions.
- Allow empty space around the video if necessary.

**Fill**
- Fill the selected canvas.
- Preserve the source video's proportions.
- Crop excess edges as necessary.
- Never stretch the video to fit.

**Crop**
- Allow the user to control which area remains visible.

Also provide Reset Transform to restore default scale and position.

## Automatic Portrait Reframing

When changing a landscape video to 9:16 or 4:5:
- Recalculate the video's scale and position for the new canvas.
- Use sensible center-crop framing by default in Fill mode.
- Do not shrink the landscape video into a small rectangle in the middle of a portrait canvas unless Fit mode is selected.
- Avoid excessive zooming.
- Keep the important central content visible as a sensible default.
- If subject tracking is not supported, use center cropping and allow manual adjustment.

## Manual Transform Controls

When a video clip is selected, provide:
- Scale / Zoom
- Horizontal position (X)
- Vertical position (Y)
- Rotation
- Fit / Fill / Crop
- Reset Transform

Allow dragging the video inside the preview to reposition it.

Each video clip must have independent transform settings.

Changing the canvas ratio must not delete timeline edits or unintentionally overwrite the transforms of every clip.

Save transform settings with the project.

## Preview and Export Must Match

Use the same calculations for scale, crop, position, and rotation in preview and export.

For example, when 9:16 at 1080 × 1920 is selected, the actual exported video must have dimensions 1080 × 1920.

Verify the actual output file dimensions and framing. A portrait-looking preview alone is not sufficient.
