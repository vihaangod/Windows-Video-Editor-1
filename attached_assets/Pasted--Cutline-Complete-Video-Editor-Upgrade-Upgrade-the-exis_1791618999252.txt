# Cutline — Complete Video Editor Upgrade

Upgrade the existing Cutline video editor into a more complete, professional video editing application. Implement all the features below while preserving the current dark-and-gold theme, existing layout style, working functionality, and saved projects.

**Important:** First inspect the existing codebase. Identify which features already exist, which are incomplete, and which are missing. Improve existing implementations instead of creating duplicates. Do not rebuild the application from scratch.

## 1. Templates — 20 Ready-Made Designs

Create a dedicated Templates section containing exactly 20 distinct, usable video design templates.

Include a variety of:

* Cinematic title designs
* YouTube intro and outro designs
* Gaming titles
* Lower thirds and name tags
* Animated headings
* Subtitle designs
* Subscribe and call-to-action overlays
* Social media promotional designs
* Chapter headings
* Modern minimal text designs

Requirements:

* Display all 20 templates in a consistent grid with preview thumbnails, names, and categories.
* Every template must have a genuinely distinct design, not just a different name or thumbnail.
* Add a preview before applying a template.
* Applying a template must create real, editable elements on the timeline, not just display a static image.
* Allow customization of text, font, size, color, position, duration, opacity, and animation wherever applicable.
* Ensure templates work with the actual video preview, timeline, project-saving system, and final export.
* Use lightweight thumbnails and avoid loading all heavy assets simultaneously.
* Do not use unlicensed copyrighted template packs.
* Do not remove existing Titles & Texts functionality.

## 4. Canvas Aspect Ratios and Social Media Formats

Upgrade the existing preview canvas controls to support actual project aspect ratios separately from preview zoom.

### Available canvas presets

* **Landscape (16:9):** Default format for normal YouTube videos.
* **Shorts / Portrait (9:16):** Vertical format for YouTube Shorts and Instagram Reels.
* **Square (1:1):** Square social media videos.
* **Instagram Portrait (4:5):** Portrait social media posts.
* **Custom:** Custom aspect ratio and dimensions, if supported by the existing architecture.

### Default Landscape

* Keep Landscape (16:9) as the default for new projects.
* Use 1920 × 1080 as the default output dimensions when appropriate.
* Preserve the existing behavior of current landscape projects.

### Shorts / Portrait

* Add a clearly visible `Shorts (9:16)` option.
* Use 1080 × 1920 as the default output dimensions when appropriate.
* Display a vertical, phone-shaped canvas centered in the preview workspace.
* Allow text, titles, overlays, and other elements to be positioned within the portrait canvas.
* Preserve existing timeline content when switching formats.
* Provide appropriate fit, crop, or background-fill options for landscape footage inside a portrait project.
* Never stretch or distort the video to fill the canvas.

### Preview zoom controls

* Keep existing Fit, Fit Canvas, and 100% zoom options if they are currently supported.
* Separate preview zoom from the actual project aspect ratio.
* Changing zoom must not change the output dimensions.
* Changing aspect ratio must update the project canvas and final export settings.

### Export and project persistence

* Save the selected aspect ratio and output dimensions with the project.
* Restore them correctly when reopening a project.
* Ensure preview, timeline composition, and final export use consistent dimensions.
* Verify that exported Landscape videos are 16:9 and Shorts videos are 9:16.
* Switching aspect ratios must not silently delete clips or reset project content.
