## 1. REDESIGN PROJECT NAME AND PROJECT MANAGEMENT

The current "Untitled cut" box in the top toolbar looks bulky and unattractive. It also makes it difficult to identify which project is currently being edited when multiple projects exist.

### Compact top toolbar

* Replace the large rounded project-name box with a compact, professional design.
* Display the active project name as clean text in the top toolbar.
* Remove the oversized background box and unnecessary dropdown styling.
* Add a subtle pencil icon or another clear rename control.
* Keep the save-status indicator close to the project name.
* Preserve the charcoal background, yellow accents, and existing toolbar functionality.
* Keep the project name readable without wasting horizontal space.

### Automatic project naming

* Use "New Project 1" as a sensible default for a newly created project.
* If that name already exists, automatically choose the next available number.
* Allow users to rename projects at any time.
* Renaming must preserve all existing edits and media references.

### Project library

Create a proper Projects screen or project library accessible from the existing Open button or a clearly labeled Projects option.

Display each project in a compact card or row containing:

* Project name.
* Last modified date and time.
* Canvas resolution.
* Frame rate.
* Optional thumbnail.
* Save status where relevant.

Provide functional actions for:

* Open Project.
* Rename Project.
* Duplicate Project.
* Delete Project.
* Save As.

Add search and sorting by project name and modification date.

### Reliable project identity and saving

* Give every project a unique internal ID independent of its display name.
* Save operations must target the currently active project ID.
* Opening another project must load that project's own timeline, text, effects, filters, transitions, and settings.
* Save As must create an independent project rather than overwrite the original.
* Duplicating a project must preserve its contents while creating a separate project identity.
* Warn users before discarding unsaved changes.
* Confirm before deleting a project.
* Do not delete the original imported media files when deleting a project.
* Do not claim that saving succeeded until the storage operation actually succeeds.

### Project status indicators

Implement accurate status feedback:

* Green: Saved.
* Yellow/amber: Unsaved changes.
* Neutral or animated indicator: Saving.
* Red: Save failed.

Update the status whenever project data changes, including text, clip positions, timing, effects, filters, transitions, markup, and project settings.

Persist project metadata using the existing storage architecture. Do not create a decorative project library that does not actually open, rename, duplicate, or delete projects.
