Build a **completely free professional video editing application for Windows**, inspired by Adobe Premiere Pro and CapCut, but without subscriptions, forced payments, or watermarks.

### Main Requirements

* Modern, clean, dark and professional UI
* Lightweight and optimized for **8 GB RAM + integrated graphics PCs**
* Fast startup and low RAM/CPU usage
* Smooth timeline even on low-end systems
* Hardware acceleration when available
* No unnecessary background processes

### Video Editing

* Import MP4, MKV, MOV, AVI, WebM and other common formats
* Import images and GIFs
* Multi-track timeline
* Cut, split, trim, crop and merge
* Drag-and-drop editing
* Undo/redo
* Speed control
* Reverse video
* Freeze frame
* Zoom and pan
* Transitions
* Video effects
* Filters
* Color correction and color grading
* Brightness, contrast, saturation, exposure, shadows and highlights
* Keyframes
* Motion controls
* Transform controls
* Rotation and scaling
* Blur effects
* Masking
* Green-screen/chroma key

### Text & Subtitles

* Add text anywhere on the video
* Multiple fonts
* Font size, color, outline and shadow
* Text animations
* Position and rotation controls
* Automatic subtitles
* Manual subtitle editing
* SRT import/export
* Subtitle timing controls

### Audio

* Multiple audio tracks
* Cut/trim audio
* Volume control
* Fade in/out
* Audio mixing
* Noise reduction
* Equalizer
* Voice-over recording
* Audio waveform display
* Separate game/system audio and microphone recording

### Recording

* Screen recording
* Webcam recording
* Microphone recording
* System/game audio recording
* Select recording resolution and FPS
* Recording directly into the editor

### Export

* MP4, MOV and other common formats
* 720p, 1080p, 1440p and 4K
* 24/30/60/120 FPS where supported
* Custom bitrate
* H.264/H.265 encoding
* Hardware encoding when available
* Presets for YouTube, Shorts, Instagram, TikTok and other platforms
* No watermark

### Project System

* Save and reopen projects
* Autosave
* Crash recovery
* Project backups
* Recent projects
* Media management
* Missing-file detection
* Proxy media system for low-end PCs

### Performance

Create a performance system specifically for weak PCs:

* Preview quality selector
* Proxy generation
* Render cache
* Hardware acceleration
* FPS monitoring
* RAM/CPU usage monitoring
* Background rendering
* Adjustable preview resolution
* Automatic performance optimization

### UI

Use a professional editor layout:

* Media/project panel
* Preview/player panel
* Timeline
* Inspector/properties panel
* Effects/transitions panel
* Audio mixer
* Export window
* Settings
* Keyboard shortcut customization

Do NOT use ugly Unicode/emoji icons. Use proper SVG/vector icons.

### Optional Advanced Features

* Local AI subtitle generation
* Local background removal
* AI noise reduction
* Smart scene detection
* Auto silence removal
* Beat detection
* Automatic captions

AI features should be **local/offline whenever possible** and must not require a paid API.

### Security & Privacy

* Process files locally
* No forced cloud upload
* No unnecessary telemetry
* No account required for basic editing
* No watermark
* No subscription

### Development Approach

Build the application in a modular architecture.

First create a **fully working foundation**:

1. UI
2. Media import
3. Timeline
4. Video preview
5. Basic cutting/trimming
6. Audio handling
7. Project save/load
8. Export

Then implement advanced effects, transitions, keyframes, subtitles, recording, proxies and AI features.

Every button and feature must actually work. Do not create placeholder buttons or fake functionality. Keep the architecture scalable so advanced features can be added without rewriting the entire application.
