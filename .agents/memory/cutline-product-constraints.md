name: Cutline product constraints
description: User-stated performance, privacy, and cost constraints for Cutline Video Editor.
---

Cutline should run locally in the browser on low-spec Windows PCs, including Intel i3-class hardware with 8 GB of RAM. Keep the editing workflow private and offline-capable; avoid cloud media uploads, paid APIs, or recurring service costs.

**Why:** the user identified this hardware and local/no-API-cost requirement as core product constraints.

**How to apply:** prefer browser-local processing and storage, bounded memory use, and efficient preview/export behavior. Clearly identify any browser codec or hardware limitation instead of silently uploading media or switching to a paid service.
